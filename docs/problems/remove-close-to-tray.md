# 移除关闭到托盘：关闭即退出，打开即保持打开

## 问题现象

用户明确要求：

> 不想要程序关闭时放在状态栏，打开就是打开关闭就是关闭。

原实现是典型的“启动器/托盘工具”行为：

- 点击自绘顶栏的关闭按钮：`hide_or_quit` → `window.hide()`，进程和托盘继续运行；
- 窗口失去焦点：winit `Focused(false)` → 自动隐藏；
- `Esc` 在没有弹层时：隐藏窗口；
- 复制命令成功：写入剪贴板后隐藏窗口；
- 唤回窗口只能靠系统托盘（部分 Linux 桌面还需要 StatusNotifierItem 扩展）。

结果就是：用户点“关闭”并没有关闭程序，窗口只是藏进托盘；失去焦点也会让窗口消失。这与“打开就是打开、关闭就是关闭”的预期冲突。

## 问题原因

这是早期产品定位（常驻托盘、复制即隐藏、随时唤回）造成的设计耦合：

- `WindowFlags` 同时承担了“托盘是否可用 / 是否正在最小化 / 文件对话框是否打开”三种失焦隐藏抑制状态；
- `install_window_event_hook` 在 `Focused(false)` 里无条件 `hide()`；
- `hide_or_quit` 把“关闭”和“隐藏”混为一谈；
- 托盘是隐藏后唯一的召回入口，因此关闭按钮不能直接退出。

只要保留“失焦自动隐藏”或“关闭隐藏到托盘”中的任意一个，就仍然需要一个隐藏进程的召回机制，无法满足“关闭就是关闭”。

## 解决方案

- **删除系统托盘**：`main.slint` 不再导入/导出 `Tray`；`main.rs` 不再创建托盘、不再应用托盘文案；`tray.slint` 保留文件但标注为停用，不参与编译。
- **删除失焦自动隐藏**：移除 `WindowFlags`、`set_dialog_open`、`minimizing`/`dialog_open`/`tray_ready` 及 `Focused(false)` 分支。文件对话框不再需要抑制隐藏。
- **关闭 = 退出**：
  - 自绘关闭按钮 → `quit-requested` → `slint::quit_event_loop()`；
  - 系统关闭（`Alt+F4` / 任务栏关闭）→ `Window::on_close_requested` → `quit_event_loop()`；
  - 复制成功 → `quit_event_loop()`（保留“复制即关闭”的产品行为）。
- **Esc 只关弹层**：没有弹层时不隐藏窗口、也不退出，什么都不做。
- **最小化保留普通语义**：只收进任务栏，不再转成托盘隐藏。
- **单实例保留**：第二次启动仍通过回环端口请求已有实例 `show_window()`；窗口最小化时会先取消最小化。
- README/中文 README 同步：删除托盘/失焦隐藏描述，关闭、复制、`Esc` 的语义改成当前行为。

## 为什么采用这个方案

- **直接满足用户语义**：关闭就是退出，打开期间窗口不会因为点击别处而消失。
- **状态大幅简化**：删掉 `WindowFlags` 后，窗口事件钩子只剩 `Esc`（弹层优先）和 `Resized`（最大化同步/尺寸记录），不会再出现“最小化被误判成失焦”“对话框导致窗口藏起来”等组合问题。
- **不保留“隐藏但无召回入口”的中间态**：如果只删托盘、保留隐藏，窗口会变成一个不可见的后台进程；如果只删失焦隐藏、保留关闭到托盘，关闭仍然不是关闭。两者必须一起删。
- 备选方案“增加一个‘关闭到托盘’设置项”没有采用：用户要求的是行为改变，不是增加配置；多一个开关只会保留复杂度。

### 权衡与限制

- **Linux 剪贴板**：复制成功后应用退出，剪贴板内容不再由本进程持续托管。`arboard` 在 X11 上 drop 时会尝试移交给剪贴板管理器；Wayland 依赖合成器/剪贴板管理器。没有剪贴板管理器的极简桌面可能粘贴不到内容，这是“复制即退出”的固有限制。
- **没有全局召回入口**：窗口关闭即进程结束，不再需要托盘；如果以后要“全局热键唤回”，需要重新引入常驻进程，属于另一个产品决策。
- **`always-on-top` 保留**：本次只改变关闭/隐藏语义，不改变窗口置顶行为。
- 本次未在本地运行 `cargo test`/`cargo build`（按项目规则），由 CI 验证。

## 解决了什么问题

- 点击关闭按钮、`Alt+F4`、任务栏关闭都会真正退出进程，不再残留托盘图标。
- 窗口失去焦点后保持打开，用户可以从任务栏正常切回。
- 最小化、单实例唤回、最大化/尺寸持久化行为保持正常。
- 不再需要托盘创建失败时的退化分支，也不会出现“无托盘但窗口已隐藏”的僵尸状态。
